# media-manager — v0 UI 设计

> **版本:** v0.1.0 | **日期:** 2026-08-16
> **前端栈:** Vue3 + Vite + Element Plus + Pinia + Vue Router（与 xhs-info-crawl 完全对齐）
> **继承基线:** [上级 Operate UI 设计](../subsystems/operate/ui.md)
> **v0 砍掉:** 工作流看板 / 发布记录 / 素材中心 / 内容日历 / 数据中心 / 规则配置 6 个页面

## 二、账号管理页（AccountsView）

### 2.1 页面布局

```
┌────────────────────────────────────────────────────────────┐
│  账号管理                                  [+ 新增账号]      │
├────────────────────────────────────────────────────────────┤
│  [平台 ▼]  [状态 ▼]  [启用 ▼]  [搜索]            [刷新]    │
├────────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 平台  | 账号名  | 状态 | 登录 | CDP | 操作          │  │
│  ├──────────────────────────────────────────────────────┤  │
│  │ 小红书 | 我的号1 | ✅ | 已登录 | 9223 | [登录态][配置][删除] │ │
│  │ 微博   | 我的号2 | ⚠️ | 已登出 | 9224 | [登录态][配置][删除] │ │
│  │ 抖音   | 我的号3 | ✅ | 已登录 | 9225 | [登录态][配置][删除] │ │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│              [上一页] 1/3 [下一页]                          │
└────────────────────────────────────────────────────────────┘
```

### 2.2 新增/编辑账号弹窗

- **平台选择**：下拉，选项为 `GET /platforms` 返回的平台（8 个）
- **账号名**：必填
- **Cookies**：JSON 文本框（高级），普通用户也可手动粘贴
- **头像 URL**：可选
- **养号配置**：`browse_count` / `like_probability` / `favorite_probability` / `daily_max_tasks` / `quiet_hours`（参考 [overview.md §4.2](./overview.md#42-配置参数每账号独立)）
- **提交**：调用 `POST /accounts` 或 `PUT /accounts/{id}`

### 2.3 操作按钮

| 按钮 | 行为 | API |
|---|---|---|
| 登录态 | 触发 whoami 检查 | `POST /accounts/{id}/whoami` |
| 配置 | 弹出养号配置编辑 | `GET/PUT /accounts/{id}/config` |
| 启用/停用 | 切换 enabled | `PUT /accounts/{id}` |
| 删除 | 软删除 | `DELETE /accounts/{id}` |
| 重新登录 | 弹出登录窗口 | `POST /accounts/{id}/relogin`（v0 跳转到 chrome cdp 端口） |

## 五、定时计划页（SchedulesView）

### 5.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  定时计划                              [+ 新增计划]          │
├─────────────────────────────────────────────────────────────┤
│  账号 [▼]  启用 [▼]                                         │
├─────────────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 名称 | 账号 | 平台 | Cron | 动作 | 启用 | 下次执行 | 操作 │  │
│  ├───────────────────────────────────────────────────────┤  │
│  │ 每日早晚养号 | 我的号1 | xhs | 0 9,21 * * * | full | ✅ | 今晚 21:00 | [编辑][启停][删除] │  │
│  │ 午间浏览 | 我的号2 | weibo | 0 12 * * * | browse | ✅ | 明天 12:00 | [编辑][启停][删除] │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 新增/编辑计划弹窗

- **账号**：下拉（只显示 active 状态）
- **名称**：必填
- **Cron**：必填，5 字段标准（参考 cron 表达式说明，提供常用模板下拉）
- **动作**：browse / like / favorite / snapshot / full
- **静默时段**："HH:MM-HH:MM" 格式
- **启用**：默认 true

## 七、与 xhs-info-crawl 前端复用

| 组件 | 来源 | 复用方式 |
|---|---|---|
| Layout / 顶部导航 / 侧边栏 | 复用 xhs | 直接 import 或拷贝 |

| API 客户端 (axios + 拦截器) | 复用 xhs | 改造 baseURL 到 media-manager |
